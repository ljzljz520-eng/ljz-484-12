# 用户手册 (User Manual)

## 1. 快速开始
欢迎使用“未来图书馆”小说阅读系统。本系统提供简洁高效的纯净阅读体验。

## 2. 功能操作指南

### 2.1 发现小说
- **浏览**: 在首页你可以看到当前系统推荐的热门小说。
- **搜索**: 使用顶部的搜索框，输入小说名称或关键词即可快速定位书籍。

### 2.2 查看书籍详情
- 点击感兴趣的小说卡片，进入详情页面。
- 你可以查看书籍的完整简介及更新章节数。
- 点击“开始阅读”将跳转到第一章，或在目录中点击特定章节进入。

### 2.3 沉浸阅读
- 阅读页采用了护眼的暖色纸质风格。
- 点击下方的“返回目录”可以随时回到书籍列表。

### 2.4 作者创作与发布
- 点击顶部导航的「作者中心」进入创作控制台，可按小说管理全部章节（含草稿）。
- 点击「新建章节」进入编辑器：支持随时「保存草稿」，草稿对读者不可见。
- 编辑器会实时显示正文字数（不计空格、换行）与占位符检测结果。
- 点击「检查并发布」时，系统会校验三项规则，**全部通过后才能标记为已发布**：
  1. **标题不能为空**（纯空格也视为空）；
  2. **正文至少 100 字**（不含空格换行），未达标会提示当前字数；
  3. **不能包含未替换的占位符**，例如 `{{标题}}`、`【待补充】`、`【请输入章节标题】`、`TODO`、`占位符` 等。
- 校验未通过时，页面会一次性列出全部问题，作者修改后可再次尝试发布；后端服务器会用相同规则再校验一次，即使绕过浏览器也无法发布不合格章节。
- 已发布章节被修改并保存后会退回草稿状态，需重新通过校验才能再次发布；草稿章节不会出现在读者端的目录中。

## 3. 常见问题 (FAQ)

**Q: 为什么系统是浅色的？**
A: 为了提供更好的可读性，系统近期升级到了全新的浅色主题。

**Q: 我可以在移动端使用吗？**
A: 是的，系统完全适配移动端浏览器，你可以通过手机进行阅读。

**Q: 数据会丢失吗？**
A: 当前版本为内存存储演示版，重启容器后台数据会重置回初始种子数据。
